# Fasto World — Redirect

Smart redirect page that detects in-app browsers (Instagram, Facebook, TikTok, etc.) and opens the website in the external browser instead.

## How it works

| Device | Behavior |
|---|---|
| **Regular browser** | Instant redirect to [fastoworld.com](https://www.fastoworld.com) |
| **Android in-app** | Automatically opens Chrome |
| **iOS in-app** | Shows a button + Safari hint |

## Setup

1. Enable GitHub Pages: `Settings → Pages → Source: main → Save`
2. Use `https://fastorochi.github.io/go/` as your Instagram bio link

## Supported Apps

Instagram · Facebook · TikTok · Snapchat · Twitter/X · LinkedIn
